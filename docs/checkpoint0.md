## 2. Стан розробки та виконана робота
1. **Репозиторій та архітектура:**
    - Налаштовано solution у складі проєктів `Core` (бібліотека ядра), `Cli` (консольний інтерфейс) та `Tests` (тестовий проєкт xUnit) на платформі .NET.
    - Реалізовано бінарні структури відповідно до `FORMAT_SPEC.md`: `TelemetryFrame` (12 байтів, Big-Endian), `PacketHeader` (43 байти, magic TLM1), `PacketPayload` (14 байтів службових полів) та коди відхилень `RejectionCode`.
    - Зафіксовано інтерфейси компонентів: `IPredictor`, `ICompressor`, `IPacker`, `IScheduler`, `ISecurity`, `IOptimizer`.

2. **Заглушки:**
    - Для всіх модулів створено початкові класи-заглушки (`MajorityClassifier`, `NoCompression`, `SequentialPacker`, `SequentialQueue`, `NoSecurity`), що забезпечує компіляцію та незалежну розробку.

3. **Вхідні дані:**
    - Підготовлено та валідовано файл телеметрії `data/session.csv` на 3000 кадрів.
