# Звіт про результати тестування модуля прогнозування (Prediction)

**Набір тестів:** `PredictionTests.cs`  
**Спосіб запуску:** `dotnet test` / Visual Studio Test Explorer  
**Загальний статус:** Всі 9 тестів пройдено успішно (0 Failed, 0 Skipped, час виконання: 266 мс)  

---

## 1. Опис та результати проходження тестів

Тестовий набір перевіряє коректність парсингу 12-байтового бінарного кадру телеметрії, обробку знакових величин, поведінку на граничних випадках і валідацію вхідних даних згідно з `FORMAT_SPEC_1` та вимогами Зрізу 1 (зона «Прогноз»).

### Тест 1. Контрольний одиничний кадр (Кейс C1.1)
* **Метод:** `ReadFrom_ReferenceSingleFrame_ParsesCorrectly`
* **Мета:** Перевірити десеріалізацію еталонного кадру телеметрії зі специфікації §1.
* **Що перевірялося:**
  * Точний 12-байтовий парсинг у форматі Big-Endian через `ReadOnlySpan<byte>` та `BinaryPrimitives`.
  * Коректність зчитування полів мітки часу, значень датчиків, прапорців `mode` та `critical`.
* **Результат:** 4 ms - Пройдено успішно.

### Тест 2. Від'ємні величини у доповняльному коді
* **Метод:** `WriteToAndReadFrom_NegativeValues_PreservesSign`
* **Мета:** Перевірити збереження знаку для знакових 16-бітних полів при серіалізації та десеріалізації.
* **Що перевірялося:**
  * Збереження від'ємного значення вібрації (`vibration = -3`, байти `FF FD`).
  * Робота зі знаковими значеннями температури й висоти без спотворення знакових розрядів.
* **Результат:** 2 ms - Пройдено успішно.

### Тест 3. Захист від системного винятку переповнення буфера (Fail-Closed)
* **Метод:** `ReadFrom_TruncatedBuffer_ThrowsArgumentException`
* **Мета:** Перевірити захист системи від витоку системних винятків (`IndexOutOfRangeException`) при пошкодженому пакеті.
* **Що перевірялося:**
  * Подача фрагментованого буфера розміром менше 12 байтів.
  * Генерація контрольованого винятку `ArgumentException` замість системної помилки індексації.
* **Результат:** < 1 ms - Пройдено успішно.

### Тест 4. Валідація меж поля режиму (Mode)
* **Метод:** `ReadFrom_ModeOutOfRange_ThrowsArgumentException` (3 тест-кейси)
* **Мета:** Перевірити дотримання допустимого діапазону 3-бітного поля `mode` ($0 \dots 7$).
* **Що перевірялося:**
  * Передача значень `mode > 7` та неприпустимих конфігурацій байта стану.
  * Блокування некоректного кадру контрольованим винятком.
* **Результат:** < 1 ms - Пройдено успішно.

### Тест 5. Валідація прапорця критичності (Critical)
* **Метод:** `ReadFrom_CriticalOutOfRange_ThrowsArgumentException` (3 тест-кейси)
* **Мета:** Перевірити валідацію однобітного прапорця `critical` ($0$ або $1$).
* **Що перевірялося:**
  * Відхилення некоректних значень бітового поля.
  * Негайне відхилення кадру за принципом fail-closed.
* **Результат:** 255 ms - Пройдено успішно.

### Тест 6. Порожній потік даних (Кейс C1.2)
* **Метод:** `ReadBinary_EmptyStream_ReturnsEmptyList`
* **Мета:** Перевірити стабільність потокового зчитувача `TelemetryReader` при нульовому розмірі входу.
* **Що перевірялося:**
  * Відсутність аварійного завершення (`EndOfStreamException`).
  * Повернення порожнього списку кадрів без помилок і без повернення `null`.
* **Результат:** 1 ms - Пройдено успішно.

### Тест 7. Базовий класифікатор (MajorityClassifier)
* **Метод:** `MajorityClassifier_ValidFrames_ReturnsZeroClass`
* **Мета:** Перевірити роботу базової заглушки моделі прогнозування для Зрізу 1.
* **Що перевірялося:**
  * Повернення класу 0 (Normal) для всіх валідних кадрів сеансу.
  * Суворе ігнорування прапорця `critical` при визначенні класу (відповідно до §9.22 методички).
* **Результат:** 4 ms - Пройдено успішно.

## 3. Висновок

* Модуль десеріалізації `TelemetryFrame`, потоковий зчитувач `TelemetryReader` та модель `MajorityClassifier` повністю відповідають вимогам першого чекпоінта.
* Забезпечено захист від витоку системних винятків (`IndexOutOfRangeException`), реалізовано підтримку від'ємних чисел у доповняльному коді та коректну роботу з порожнім вхідним потоком.
* Результати зафіксовані як базова лінія для подальшої реалізації ковзного вікна ознак (8 кадрів) та багатошарового персептрона (MLP) на наступних етапах.
